# 团标对齐：技术规范吸收与 §6 验收规程

> 对齐对象：《基于AI人工智能机器视觉缺陷检测技术规范》T/CITS 团体标准**草案**
> （中国检验检测学会立项，苏州锐新视科技有限公司起草，版本 2026-03-22，
> 文件 `1_[基于AI人工智能机器视觉缺陷检测技术规范]10_15_(1).pdf`）。
> 规范尚处草案阶段（原文含未解决批注），本文档随定稿版更新；
> 门槛数值全部参数化，定稿后只改数值不改架构。

总原则：

- **验收层与运行层分离**：§6 门控只存在于离线评估脚本（PASS/FAIL），
  运行时检测链路不加门控、不做超时跳源——零漏检架构不可让步。
- **诚实优先**：测不达标如实记录为风险项，不用有利口径糊弄。
- **口径显式化**：每项指标声明测量口径（阈值、样本、定义层级），
  抢占审计解释权。

## 二、§6.2 定位精度验收规程（代码门控）

唯一可 bbox 门控的条款：仅 YOLO 源有框级真值（PatchCore/DINOv2 异常源
无 bbox GT，GDINO 无标注集）。

```bash
python finetune/evaluate_yolo.py --gate                  # 标准档
python finetune/evaluate_yolo.py --gate --spec-tier high # 高精度档
```

- **主门控（唯一 FAIL 依据）：mAP@50**。标准档 ≥0.80，高精度档 ≥0.85。
  mAP 为 PR 曲线下面积，与 conf 阈值无关、不可被参数选择操纵。
- **次级参考（仅打印不 FAIL）：Precision/Recall ≥85/85**（高精度档 90/90）。
  P/R 是 PR 曲线单点值，仅作对照参考；与 mAP 同用 ultralytics val
  默认口径测量（单一口径，避免门控基准漂移）。
- FAIL 时进程 exit 1，供 CI/验收脚本消费。

## 三、§6.3 识别精度验收规程（口径映射，零新增代码）

测量基座为 `scripts/eval_acceptance.py`（kolektor/pcb/paired 等模式），
映射关系：

| 规范指标 | 仓库口径 | 出处 |
|---|---|---|
| 误检率 ≤15%（高精 10%） | union `fpr_hold`（留出正常图被判 NG 比例） | eval_block |
| 漏检率 ≤15%（高精 10%） | `missed / n_def`（双源均漏的缺陷比例） | eval_block |
| 识别准确率 ≥80%（高精 85%） | Union Recall（图像级） | eval_block |

**口径声明：图像级判定**（一张图任一源判 NG 即 NG）。规范未定义
框级/图级，多源 Union 下框级定义会打架，本文档主动声明图级口径。
零漏检 OR 架构下漏检率结构性趋零（Union OR + REVIEW 黄牌兜底），
门槛天然满足。

**风险项（如实记录）**：贵司批注"误检 2%/漏检 1%"严于团标高精档。
现行 NP `eps=0.10` 运行点约为 10% 误检量级；达到 2% 需切
`eps≈0.02` 运行点并保证足量 n_cal（≥30，见 calibration 模式）。
`eps_sweep` 输出已提供各 eps 运行点的 FPR/Recall 数据作为选型依据。

## 四、§6.1 检测速度验收规程（咨询性测量）

规范口径为"单张图像平均检测耗时"。测量协议：

1. 用 `eval_acceptance.py` 各模式输出的 `infer_ms`（单引擎推理口径，
   JSON 结果含 `speed_scope` 字段标注）；Union 全链路端到端实测
   （run_union_detection wall-time）另立任务。
2. 剔除 warmup 前 N 张（首次推理含模型加载，会污染滑窗均值）。
3. 样本量 ≥100 张（对应规范 §7 测法），明示硬件型号。

判定为**咨询性 PASS/WARN**（单引擎 ≤1s 为 PASS 参考线），不 exit 1：
规范自批注"检测时间和硬件相关"，速度基准归属部署 profile
（profiles/gpu-full、edge-jetson、cpu-only）逐档声明。
运行时禁止以"超时"为由跳过检测源。

## 五、§6.4 数据留存设计原则（P2d 登记，本期不实现）

规范原文为"**至少** 90 天"，由此确定设计方向——**归档优先，删除默认关闭**
（产线追溯/客户审计场景下自动删除=销毁证据）：

- 近 `retention_days`（默认 90，config 可配）天数据热在线
  （SQLite qc_results + qc_images）；
- 超期转冷存档（压缩目录 + 保留 DB 索引），可检索；
- 物理删除功能默认关闭，显式开启方可用；
- 已知风险：qc_images 为 BMP 大图无上限累积，磁盘写满时持久化
  行为链需在 P2d 实现时一并核实。
